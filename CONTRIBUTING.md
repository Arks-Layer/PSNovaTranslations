# Contributing

Thank you for wanting to help with PS: Nova Translations. This project is on GitHub so that people can use it and improve it together. The best way to improve it is to send your changes back here.

If you are an AI agent or are using one, read [AGENTS.md](AGENTS.md) as well. It sets rules that agents must follow in this repository.

## Who can contribute what

- **Translation edits.** Please only submit translation edits if you have a grasp of Japanese. We appreciate the enthusiasm, but translations made through Google Translate or similar tools are not accepted.
- **Proofreading.** If you do not understand Japanese, you can still help by checking translated lines for grammar and spelling. Use US English.
- **Discussion.** You may open an issue to discuss a translation with other translators. Issues that are not related to translation may be deleted without notice.

## Contributions must come from a human

We do not accept pull requests from LLMs or AI agents.

- Every pull request must be reviewed and typed up by a human, who submits it under their own account and is responsible for it.
- Do not have an AI agent open, update, or write a pull request, an issue, or a review comment for you.
- Do not paste AI-generated or machine-translated text into a contribution. What you submit must be written by you.
- You should be able to explain every change you submit. If a maintainer asks why a line was translated a certain way, "the tool suggested it" is not an answer.

Pull requests that appear to be generated by an AI will be closed without review.

The maintainers' own use of AI is described in the AI Disclosure section of the [README](README.md). It is limited to technical problems such as crashes and display bugs. AI is not used for the translation.

## How to contribute

A full guide to getting set up is on the wiki: [How to contribute](https://github.com/Arks-Layer/PSNovaTranslations/wiki/How-to-contribute).

1. Fork this repository with GitHub's fork button, so your copy stays linked to this one.
2. Create a branch in your fork for your change.
3. Make your edits, following the editing rules below.
4. Open a pull request against this repository and describe what you changed and why.
5. Respond to review comments. A maintainer may ask for changes before merging.

Keep each pull request to one topic, such as one file or one set of related lines.

## Editing rules

Each entry looks like this:

```
  "310040": {
    "OriginalText": "ポストアタック",
    "Text": "Post Attack",
    "Enabled": true
  },
```

- Put your translation in the `Text` field, then change `Enabled` from `false` to `true`.
- Do not change the line's ID, the field names, or `OriginalText`.
- Leave control codes such as `\n`, color codes, variables, and button icons intact, and only use variables in the messages they belong to. See [Control Codes](README.md#control-codes).
- Keep text within the size limits for its region so the game does not shrink it. See [Entry Sizes](README.md#entry-sizes).
- Replace Japanese quotation marks, numbers, and punctuation with their English counterparts.
- Follow the project's capitalization rules for titles, buttons, and names. See [Capitalization](README.md#capitalization).
- Follow the terminology already used in the project, so names and terms stay consistent. If you think an existing term is wrong, raise it in an issue first instead of changing it in a few places.

The [README](README.md) has the full details for each of these.

## Reporting problems

If you find a mistranslation or a typo and do not want to fix it yourself, open an issue. Say where the text appears in the game, what it says now, and what you think it should say. A screenshot helps.

## What not to include

Do not add files that are not ours to share:

- Proprietary CRIWARE files, including .CPK archives and any CRIWARE audio format.
- Game data or other material owned by SEGA, beyond the text entries the project already contains.

## Credit and ownership

- By submitting a contribution, you agree that it becomes part of this project and is covered by the same rules as the rest of the repository.
- This project has no license. Do not add one in a pull request, including license headers in files.
- Only submit work that is your own. Do not copy text from other translations.
- Contributors are credited through the project's commit history.

## Forks, other languages, and re-releases

- **Forks.** You are welcome to fork this repository on GitHub. Keep the fork linked to this repository, and keep the history, AGENTS.md, and credit to Arks-Layer intact.
- **No license.** This project has no license and is shared in good faith under the rules here. That does not make it free to take. Do not add a license to a fork or to any project that contains our work, and do not describe our work as open source or as released under any license.
- **English hard forks.** Do not re-release this project, or an edited or "improved" version of it, as a separate English project. If you have improvements, send them here. A separate English project must be translated from scratch from the Japanese and must not use our translation, files, or tools.
- **Other languages.** We opened this repository hoping it would help players enjoy the game in their own languages. A separate project that translates the game into a language other than English is allowed, as long as Arks-Layer is credited first and foremost. If the translation was made from our English text, it must say so and must not be presented as an original translation.
- **Groundwork credit.** Any project that uses anything from this repository or from our tools must credit Arks-Layer for the initial framework that made translating the game possible. If you do not want to give that credit, do not use our work.

The full rules are in [AGENTS.md](AGENTS.md). They apply to people as well as to AI agents.
